# DaneTree Common Library

Shared Java models for the DaneTree backend stack.

## Contents

- `entities` for core domain entities
- `dtos` for API/service transfer models
- `enums` for shared constrained value sets

## Build

```bash
cd common-library
mvn -DskipTests package
```

## Install locally for other modules

```bash
cd common-library
mvn -DskipTests install
```
